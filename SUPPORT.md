# Memory Weaver Support

For setup problems or non-sensitive bugs, [open an issue](https://github.com/BrandonDucar/memory-weaver/issues).
Include the exact commit or release, operating system, Node/browser version,
whether you use the browser app or local companion, expected behavior and the
smallest synthetic reproduction. Search existing issues first.

The [main README](README.md) covers browser development and current limitations.
The [local companion guide](desktop/README.md) covers its default-deny manifest,
build and commands. A declared connector is not necessarily an implemented
native driver; consult the connector-state section before enabling it.

Issues are public. Do not attach vaults, tokens, private repositories, mailbox
exports, personal documents or unredacted configuration. For exploitable
vulnerabilities use [private reporting](SECURITY.md), not an ordinary issue.

For cross-product proposals, use the [DreamNet integration intake](https://github.com/BrandonDucar/BrandonDucar/issues/new?template=02-integration.yml&product=memory-weaver).
Memory Weaver remains independently usable; private DreamNet access is not
required. A support request does not promise a fix, response deadline, paid
service or production approval.
